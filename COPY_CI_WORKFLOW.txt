# 📋 复制以下内容到 GitHub

## 文件位置
GitHub: `https://github.com/Nigtunt/komga-reader`
操作：Add file → Create new file
文件名：`.github/workflows/ci.yml`

---

## ci.yml 完整内容

```yaml
name: Flutter CI

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main, develop ]

jobs:
  build:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v3
      
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.x'
          channel: 'stable'
          cache: true
      
      - name: 安装依赖
        run: flutter pub get
      
      - name: 检查代码格式化
        run: dart format --output=none --set-exit-if-changed .
      
      - name: 静态分析
        run: flutter analyze
      
      - name: 运行测试
        run: flutter test
      
      - name: 构建 Debug APK
        run: flutter build apk --debug
      
      - name: 上传 APK
        uses: actions/upload-artifact@v3
        with:
          name: debug-apk
          path: build/app/outputs/flutter-apk/app-debug.apk
```

---

## 提交信息

在页面底部的 "Commit new file" 输入框填写：
```
feat: 添加 CI 工作流
```

然后点击 **Commit new file** 按钮。

---

## 提交后操作

1. 等待几秒钟
2. 点击顶部的 **Actions** 标签
3. 应该能看到 "Flutter CI" 工作流
4. 构建会自动开始（或手动点击 "Run workflow"）

---

## 快速验证

构建开始后，访问：
https://github.com/Nigtunt/komga-reader/actions

查看构建状态：
- 🟡 黄色 = 正在运行
- 🟢 绿色 = 成功
- 🔴 红色 = 失败
